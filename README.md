# Abir Scoping Review Dashboard

A standalone GitHub Pages project tracker for the scoping review.

## Add it to kayavanroost.github.io

1. Copy the `abir-scoping-review` folder into the root of the `kayavanroost.github.io` repository.
2. Commit and push.
3. With GitHub Pages already enabled for the repository, the page should be available at `/abir-scoping-review/`.

The checkboxes use browser `localStorage`: progress persists on the same browser/device but is not synchronized between collaborators. To make status shared across users, edit the HTML in GitHub or add a backend/GitHub Issues integration later.

## Customize

Replace the placeholder project-link labels in `index.html` with URLs for Covidence, Zotero, OneDrive, and OSF. The current-phase card can also be updated as the project advances.
